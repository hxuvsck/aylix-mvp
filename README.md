# Aylix MVP

Aylix is a human navigation layer for travel.

It connects a traveler to a relevant local through a live audio call.

---

## MVP

Flow:

1. Set context
2. Find a local
3. Match
4. Audio call
5. Review

---

## Stack

- Expo (mobile + web)
- Express (API)
- Postgres + Redis (Docker)

---

## Run

### API

cd api
npm install
npm run dev


### App

cd app
npx expo start
